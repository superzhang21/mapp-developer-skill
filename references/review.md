# 提审与发布

## 准备材料

- 应用名称、用途、说明、图标，以及**可重复的操作步骤**。
- 新版本的 `app.zip`，manifest 的 `id` 用应用页面分配的值。
- 每项权限的用途；相对上一版的权限、依赖、资源和数据流变化。
- 每个网络端点的运营方、用途、参数和响应示例。
  受保护接口要提供 JWT 验证与业务授权说明；sandbox 与正式数据分开。
- 使用 CDN 素材时，提交 `remote_assets` 固定清单：每个素材的用途、来源、
  CDN 运营方，以及对应文件的大小、MIME、SHA-256。
  按审核员要求提供与清单哈希一致的原文件。
  **远程素材不随 ZIP 上传，不代表已经完成内容审核。**
- 依赖和素材来源；保留源码及可复现构建步骤，按审核员要求提供。

补充材料按社区指定渠道提交，注明应用 ID 和版本。**包内不得保存秘密凭据。**

## 开发与发布流程

1. 在社区个人资料的应用页创建应用，填写名称、说明和图标；复制应用 ID，填入 manifest。
2. 使用示例项目或 SDK 开发，**只申请实际需要的权限**。
3. 在沙箱页签上传 `dist/package/app.zip` 并保存，等待构建处理完成。
4. 沙箱页签列出每个构建，固定有效期 **7 天**，也可手动过期（不可恢复）。
   在正式页新建发布，选择版本与构建，填写更新说明和审核备注；提审中可以撤回。
5. 在 `/apps-sandbox/<app-id>/<version>-<8-char-sha>` 检查实际运行。
   作者需有开发者资格，管理员可预览审核。
6. 正式审核和处理完成后收到系统私信，再手动上线。
   新发布版本必须高于已发布的最高版本；历史正式版可重新上线回滚。

## 提交流程

1. 上传并保存 ZIP，等待 sandbox 就绪的系统私信。
2. 同一版本可上传多个沙箱构建。测试完成后，在正式页点击"新建发布"，
   选择版本与构建，填写更新说明和审核备注；审核期间可撤回。
3. 作者和管理员访问 `/apps-sandbox/<app-id>/<version>-<8-char-sha>` 检查精确版本。
   **sandbox 不是公开分享链接。**
4. 管理员在社区审核队列处理申请，系统私信通知发布结果。
5. 正式包就绪后，作者选择生效版本；最多一个，也可全部取消以暂时下架。

## 提交前自查

- [ ] ZIP 由 SDK `pack` 生成，ID/版本/权限/资源一致，无额外文件或秘密。
- [ ] 首屏调用了 `lifecycle.ready()`；游客、拒绝权限或 API 失败时能正常反馈。
- [ ] 手机、键盘、深浅主题、存储恢复、离开再打开均可用。
- [ ] 只使用公开 SDK，不访问父 DOM、论坛 Cookie、其他应用或绕过网络限制。
- [ ] 剪贴板、全屏和媒体由明确操作触发；不伪装社区登录或诱导输入密码。
- [ ] HTTP 服务配置了 CORS；JWT 缺失/无效时拒绝，不能回退 Cookie 鉴权。
      WS 在 upgrade 前验证 JWT 并限制连接寿命。
- [ ] CDN 素材申请了 `assets.remote`，公开 HTTPS 地址允许 CORS GET、
      无重定向和登录要求；真实文件大小、MIME、SHA-256 与清单一致，
      加载失败有反馈。修改内容或地址后更新清单并重新提审。
- [ ] sandbox 中检查的是本次申请版本和同一份 ZIP。

## 拒绝、下架与处罚

- 沙箱构建固定保留 7 天，开发者也可手动使构建过期。
  **过期不可恢复**，记录保留，未引用的文件交由论坛清理；不能继续测试或提审。
- 被正式流程引用的原稿和审核预览会保留；过期预览仅供管理员审核，
  不延长作者测试期。
- 拒审后按私信原因修改并上传新构建，再重新提审。
- **已正式发布的版本不能替换内容。**
- 举报针对指定正式版本；被永久锁定的版本不能修改、删除重建、重新提审或激活。
  作者可选择其他未锁定的已审核版本，或提交新版本。
- 应用被禁用时不能靠切换版本恢复；作者被封禁时，其全部应用停止运行。
- 申诉走社区指定渠道。
- 公开分享使用正式页面的 iframe 分享按钮；未登录时不能举报或评分，
  嵌入页沿用论坛可用的登录状态。

## 常见被拒原因

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `APP_ID_MISMATCH` | manifest 的 `id` 与应用页不一致 | 原样复制应用页的 ID |
| `BUILD_EXISTS` | 相同 SHA-256 的 ZIP 提交过 | 改内容或升版本后重新打包 |
| 首屏空白 | 没调 `lifecycle.ready()` | 首次渲染后调用一次 |
| 权限被驳回 | 申请了用不到的权限 | 只保留真正使用的 |
| 端点被驳回 | 指向无权运营的服务 | 换成自己的服务并说明归属 |
| 素材被驳回 | CDN 未开放论坛 origin 的 CORS GET | 补 CORS 头并提供 SHA-256 |
| 沙箱构建消失 | 超过 7 天有效期 | 重新打包上传 |
